Portable Web Spaces

A general purpose permissioned storage API. Spaces hold Collections, Collections hold Resources, and every request is authorized with capabilities rooted in a DID you control.

Formerly Wallet Attached Storage (WAS). The specification is being renamed; the current editor's draft is at w3c-ccg.github.io/wallet-attached-storage-spec.

read the spec → github

Introduction

Portable Web Spaces brings together lessons learned from many attempts to standardize permissioned cloud storage. The specification provides:

  • A set of design constraints, goals, and requirements.
  • A tiered, composable data model for storage primitives.
  • An HTTP API binding for storage operations.
  • An authorization profile based on DIDs, zCaps, and HTTP Signatures.
note

A conformant minimal server implements only Resource CRUD and the authorization profile. Every other endpoint group is optional.
